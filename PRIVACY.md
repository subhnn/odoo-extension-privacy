# Privacy Policy for Odoo QWeb Navigator

Odoo QWeb Navigator is a Chrome extension for inspecting QWeb templates connected to Odoo report print actions.

## Data Access

The extension runs only when the user clicks the extension icon on an active browser tab. It reads content from the active Odoo page and makes read-only same-origin requests to the active Odoo instance using the user’s existing authenticated Odoo session.

The extension may access Odoo report names, report technical identifiers, QWeb view names, XML IDs, database IDs, template inheritance relationships, and related view metadata.

## Data Collection and Storage

Odoo QWeb Navigator does not collect, store, transmit, sell, or share user data with third parties.

The extension does not store passwords, credentials, authentication tokens, or personal information.

## Remote Services

The extension does not use external APIs, analytics, telemetry, advertising, or remote code.

All scripts, styles, and assets are packaged with the extension.

## Purpose

Data accessed by the extension is used only to display QWeb template relationships for the selected Odoo report.
